MGA TAMPOK

Lahat ng kailangan mong tool para sa mga pahina, sa iisang lugar

Magbukas ng PDF, pumili ng mga pahina, at gawin ang iyong mga pagbabago. Ayusin ang mga dokumento sa iyong device nang walang komplikadong editing environment.

⊕

Pagsamahin ang mga PDF

Magdagdag ng isa pang PDF at pagsamahin ang maraming dokumento.

↕

Ayusin at kumuha

Baguhin ang ayos, kopyahin o alisin ang mga pahina, at i-export lamang ang mga napili.

↻

I-rotate at magsingit

I-rotate ang mga napiling pahina o magsingit ng blangkong pahina bago o pagkatapos ng mga ito.

ⓘ

I-edit ang detalye

Suriin at baguhin ang pamagat, may-akda, paksa at mga keyword.

▣

Itakda ang mga kagustuhan sa pagtingin

I-save sa PDF ang layout ng pahina, pagpapakita ng cover at direksyon ng pagbasa.

⌑

Proteksiyon ng password

Itakda o alisin ang password na kailangan upang buksan ang na-export na PDF.

◴

Mga diagnostic sa device

Magpatakbo ng performance test at tingnan o kopyahin ang mga diagnostic log mula sa Settings > Version Information. Nananatili sa iyong device ang mga resulta at log.
