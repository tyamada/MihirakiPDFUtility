Support

We welcome questions, suggestions and bug reports. Please review the information below before contacting us.

Getting started

  1. Select Open PDF and choose the file you want to edit.
  2. Select pages and use the Edit Pages menu to reorder, rotate, duplicate or remove them.
  3. To merge another PDF, choose Add PDF from the Document menu.
  4. When you are finished, use the save button in the upper-left corner to export a new PDF.

Frequently asked questions

Does the App overwrite the original PDF?

You choose where to export the edited document. Check the destination and filename before saving.

Can the App open a PDF if I have forgotten its password?

No. An encrypted PDF requires the correct password. The App does not analyze or bypass passwords.

Are features restricted unless I make a purchase?

No. All PDF editing features are available without a purchase. The optional In-App Purchases unlock Bronze, Silver, or Gold supporter icons permanently.

Can I restore a support purchase?

Yes. Supporter icons are non-consumable purchases. Select Restore Purchases on the Supporter Icons screen to restore previously purchased icons.

Products or prices are not displayed

Check your internet connection and App Store sign-in, wait briefly, and select Try Again. Products may be temporarily unavailable due to an App Store issue.

Are my PDF files uploaded?

The App has no feature that uploads PDFs to a server operated by the Developer. See the Privacy Policy for details.

Performance tests and diagnostic logs

Open Settings, select Version Information, then choose Run Performance Test to measure CPU, memory and PDF processing on the current device. The result includes the test date, device and OS information and can be copied to the clipboard.

Choose View Diagnostic Logs on the same screen to review and copy recent app lifecycle, PDF operation, editing and timing records. Logs never include file names, file paths, PDF contents, document metadata, passwords or other personal information. The App has no feature that sends test results or logs externally, and log records older than 14 days are deleted automatically.

Contact and bug reports

Contact us on GitHub

Please include the following details. Do not attach a PDF publicly if it contains personal or confidential information.

  • App version and build number
  • iPhone or iPad model
  • iOS or iPadOS version
  • Steps that reproduce the issue
  • Any error message displayed
  • Copied performance test results or diagnostic logs, if relevant
