Política de privacidad

Última actualización: 5 de octubre de 2026

Esta Política de privacidad explica cómo tyamada (el «Desarrollador») trata la información en Mihiraki PDF Utility (la «Aplicación»).

1. Archivos PDF

Los archivos PDF seleccionados en la Aplicación y los cambios que realizas se procesan en tu dispositivo para ofrecer las funciones de la Aplicación. La Aplicación no incluye ninguna función que envíe, almacene o recopile tus archivos PDF en un servidor operado por el Desarrollador.

2. Recopilación de datos

La Aplicación no envía datos personales, como tu nombre, dirección de correo electrónico, ubicación, contactos, historial de navegación o identificador publicitario, a ningún servidor operado por el Desarrollador. No se requiere una cuenta de usuario.

3. Registros de diagnóstico locales

Para ayudar a identificar bloqueos, lentitud y problemas de funcionamiento o visualización, la Aplicación guarda registros de diagnóstico únicamente en tu dispositivo. Los registros pueden incluir tipos de operaciones, resultados, tiempos y recuentos de páginas. No incluyen nombres ni rutas de archivo, contenido ni metadatos de documentos, contraseñas ni información personal. La Aplicación no incluye ninguna función que envíe estos registros al exterior. Puedes consultarlos y copiarlos desde Ajustes > Información de la versión. Las entradas con más de 14 días se eliminan automáticamente.

4. Compras dentro de la aplicación

Las compras opcionales de apoyo se procesan mediante StoreKit de Apple y la App Store. El Desarrollador no recibe ni almacena directamente datos de pago, como números de tarjeta de crédito. La política de privacidad de Apple se aplica a la información procesada por Apple.

5. Servicios de terceros

La Aplicación no incluye SDK publicitarios ni SDK analíticos de terceros destinados al seguimiento del comportamiento. Los términos y políticas de Apple se aplican a la App Store, StoreKit y los servicios del sistema operativo.

6. Este sitio web

Este sitio web está alojado en GitHub Pages. La Declaración de privacidad de GitHub puede aplicarse a la información técnica generada cuando accedes al sitio. Este sitio web no utiliza cookies, publicidad ni análisis propios.

7. Privacidad infantil

La Aplicación no recopila intencionadamente datos personales de personas de ninguna edad.

8. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones de la Aplicación o los requisitos aplicables. Los cambios importantes se anunciarán en esta página.

9. Contacto

Si tienes preguntas sobre esta política, contacta con el Desarrollador mediante GitHub Issues.
