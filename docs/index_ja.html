PDF PAGE ORGANIZER

PDFのページ整理を、もっとシンプルに。

結合、並べ替え、回転、削除、プロパティ編集、閲覧用パスワード設定。日常のPDF作業に必要な機能を、分かりやすいひとつのアプリにまとめました。

機能を見る使い方・サポート
FEATURES

必要なページ操作を、ひとつの画面で

PDFを開き、ページを選択して操作します。複雑な編集環境を用意せず、端末上で文書を整理できます。

⊕

PDFを結合

別のPDFを追加し、複数の文書をひとつにまとめられます。

↕

並べ替えと抽出

ページの順序変更、複製、削除、選択ページだけの保存に対応します。

↻

回転と空白ページ

選択ページの回転や、前後への空白ページ挿入ができます。

ⓘ

文書情報を編集

タイトル、作成者、サブタイトル、キーワードを確認・変更できます。

▣

表示方法を設定

ページレイアウト、表紙表示、スクロール方向をPDFへ保存します。

⌑

パスワード保護

PDFを開くための閲覧用パスワードを設定・解除できます。

◷

端末内診断

実機性能テストと診断ログの確認・コピーに対応します。結果やログを外部へ送信する機能はありません。
