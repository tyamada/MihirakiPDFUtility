Dukungan

Kami menerima pertanyaan, saran, dan laporan bug. Harap tinjau informasi berikut sebelum menghubungi kami.

Memulai

  1. Pilih Open PDF lalu pilih file yang ingin diedit.
  2. Pilih halaman dan gunakan menu Edit Pages untuk mengubah urutan, memutar, menduplikasi, atau menghapusnya.
  3. Untuk menggabungkan PDF lain, pilih Add PDF dari menu Document.
  4. Setelah selesai, gunakan tombol simpan di sudut kiri atas untuk mengekspor PDF baru.

Pertanyaan umum

Apakah Aplikasi menimpa PDF asli?

Anda memilih lokasi ekspor dokumen yang diedit. Periksa tujuan dan nama file sebelum menyimpan.

Bisakah Aplikasi membuka PDF jika saya lupa kata sandinya?

Tidak. PDF terenkripsi memerlukan kata sandi yang benar. Aplikasi tidak menganalisis atau melewati kata sandi.

Apakah fitur dibatasi jika saya tidak membeli?

Tidak. Semua fitur pengeditan PDF tersedia tanpa pembelian. Pembelian Dalam Aplikasi opsional membuka ikon pendukung Bronze, Silver, atau Gold secara permanen.

Bisakah saya memulihkan pembelian dukungan?

Ya. Ikon pendukung adalah pembelian non-konsumsi. Pilih Restore Purchases di layar Supporter Icons untuk memulihkan ikon yang pernah dibeli.

Produk atau harga tidak ditampilkan

Periksa koneksi internet dan status masuk App Store, tunggu sebentar, lalu pilih Try Again. Produk mungkin sementara tidak tersedia karena masalah App Store.

Apakah file PDF saya diunggah?

Aplikasi tidak memiliki fitur yang mengunggah PDF ke server milik Pengembang. Lihat Kebijakan Privasi untuk detail.
