Kebijakan Privasi

Terakhir diperbarui: 22 September 2026

Kebijakan Privasi ini menjelaskan cara tyamada (“Pengembang”) menangani informasi di Mihiraki PDF Utility (“Aplikasi”).

1. File PDF

File PDF yang dipilih di Aplikasi dan editan Anda diproses di perangkat untuk menyediakan fitur Aplikasi. Aplikasi tidak memiliki fitur yang mengirim, menyimpan, atau mengumpulkan file PDF Anda di server milik Pengembang.

2. Pengumpulan data

Aplikasi tidak mengirim data pribadi seperti nama, alamat email, lokasi, kontak, riwayat penelusuran, atau pengenal iklan ke server milik Pengembang. Akun pengguna tidak diperlukan.

3. Pembelian Dalam Aplikasi

Pembelian dukungan opsional diproses melalui StoreKit Apple dan App Store. Pengembang tidak menerima atau menyimpan langsung detail pembayaran seperti nomor kartu kredit. Kebijakan privasi Apple berlaku untuk informasi yang diproses Apple.

4. Layanan pihak ketiga

Aplikasi tidak menyertakan SDK iklan atau analitik pihak ketiga untuk pelacakan perilaku. Ketentuan dan kebijakan Apple berlaku untuk App Store, StoreKit, dan layanan sistem operasi.

5. Situs web ini

Situs web ini dihosting di GitHub Pages. Pernyataan Privasi GitHub dapat berlaku untuk informasi teknis yang dihasilkan saat Anda mengakses situs. Situs ini tidak menggunakan cookie, iklan, atau analitik miliknya sendiri.

6. Privasi anak

Aplikasi tidak secara sengaja mengumpulkan data pribadi dari siapa pun pada usia berapa pun.

7. Perubahan kebijakan

Kebijakan ini dapat diperbarui saat fitur Aplikasi atau persyaratan yang berlaku berubah. Perubahan penting akan diumumkan di halaman ini.

8. Kontak

Untuk pertanyaan tentang kebijakan ini, hubungi Pengembang melalui GitHub Issues.
