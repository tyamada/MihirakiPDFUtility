Informativa sulla privacy

Ultimo aggiornamento: 27 novembre 2026

La presente Informativa sulla privacy spiega come tyamada (lo «Sviluppatore») gestisce le informazioni in Mihiraki PDF Utility (l’«App»).

1. File PDF

I file PDF selezionati nell’App e le modifiche apportate vengono elaborati localmente sul dispositivo per fornire le funzionalità dell’App. L’App non dispone di alcuna funzione per inviare, archiviare o raccogliere i file PDF su server gestiti dallo Sviluppatore.

2. Raccolta dei dati

L’App non invia dati personali quali nome, indirizzo e-mail, posizione, contatti, cronologia di navigazione o identificatore pubblicitario a server gestiti dallo Sviluppatore. Non è richiesto alcun account utente.

3. Log e report di diagnostica sul dispositivo

L’App memorizza record di diagnostica limitati sul dispositivo per aiutare a individuare sequenze di operazioni, chiusure impreviste, rallentamenti e altri malfunzionamenti. I record possono includere tipi di evento, esiti, tempi di elaborazione e conteggi di pagine. Non includono mai nomi o percorsi di file, contenuti PDF, metadati del documento, password, nome del dispositivo o altri dati personali.

I log di diagnostica sono conservati localmente sul dispositivo e i record più vecchi di 14 giorni vengono eliminati automaticamente. L’App non invia automaticamente log di diagnostica o risultati dei test all’esterno. I report di diagnostica possono essere consultati direttamente dall’utente nell’App e, se desiderato per supporto o segnalazioni, copiati negli appunti o condivisi manualmente tramite il foglio di condivisione di sistema.

4. Acquisti in-app

Gli acquisti di supporto facoltativi sono gestiti tramite StoreKit di Apple e l’App Store. Lo Sviluppatore non riceve né memorizza direttamente i dati di pagamento come i numeri di carta di credito. Alle informazioni elaborate da Apple si applica l’informativa sulla privacy di Apple.

5. Servizi di terze parti e PDF di esempio

L’App non include SDK pubblicitari o SDK di analisi di terze parti destinati al tracciamento comportamentale. All’App Store, a StoreKit e ai servizi del sistema operativo si applicano i termini e le informative di Apple.

Quando scegli di scaricare i documenti PDF di esempio all’interno dell’App, i file vengono scaricati da GitHub (GitHub Releases). Le informazioni tecniche generate durante l’accesso di rete (come gli indirizzi IP) sono soggette all’Informativa sulla privacy di GitHub.

6. Questo sito web

Questo sito web è ospitato su GitHub Pages. Alle informazioni tecniche generate durante l’accesso al sito può applicarsi l’Informativa sulla privacy di GitHub. Questo sito web non utilizza cookie propri, pubblicità né strumenti di analisi.

7. Privacy dei minori

L’App non raccoglie intenzionalmente dati personali da persone di qualsiasi età.

8. Modifiche alla presente informativa

La presente informativa può essere aggiornata al variare delle funzionalità dell’App o dei requisiti applicabili. Le modifiche sostanziali saranno annunciate su questa pagina.

9. Contatti

Per domande sulla presente informativa, contatta lo Sviluppatore tramite GitHub Issues.
