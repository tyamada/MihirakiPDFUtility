Suporta

Tinatanggap namin ang mga tanong, mungkahi at bug report. Pakibasa ang impormasyon sa ibaba bago makipag-ugnayan.

Pagsisimula

  1. Piliin ang Open PDF at piliin ang file na gusto mong i-edit.
  2. Pumili ng mga pahina at gamitin ang Edit Pages menu upang ayusin, i-rotate, kopyahin o alisin ang mga ito.
  3. Upang magsama ng isa pang PDF, piliin ang Add PDF sa Document menu.
  4. Kapag tapos na, gamitin ang save button sa kaliwang itaas upang mag-export ng bagong PDF.

Mga madalas itanong

Ino-overwrite ba ng App ang orihinal na PDF?

Ikaw ang pipili kung saan ie-export ang na-edit na dokumento. Suriin ang destinasyon at filename bago mag-save.

Mabubuksan ba ng App ang PDF kung nakalimutan ko ang password?

Hindi. Kailangan ng encrypted PDF ang tamang password. Hindi sinusuri o nilalampasan ng App ang mga password.

May mga tampok bang limitado kung hindi ako bibili?

Wala. Available ang lahat ng PDF editing feature nang walang pagbili. Permanenteng ina-unlock ng opsiyonal na In-App Purchase ang Bronze, Silver, o Gold supporter icon.

Maaari ko bang i-restore ang support purchase?

Oo. Non-consumable purchase ang mga supporter icon. Piliin ang Restore Purchases sa Supporter Icons screen upang ibalik ang mga dating biniling icon.

Hindi ipinapakita ang mga produkto o presyo

Suriin ang internet connection at App Store sign-in, maghintay sandali, at piliin ang Try Again. Maaaring pansamantalang hindi available ang mga produkto dahil sa problema sa App Store.

Ina-upload ba ang aking mga PDF file?

Walang tampok ang App na nag-a-upload ng PDF sa server ng Developer. Tingnan ang Patakaran sa Privacy para sa detalye.

Performance test at mga diagnostic log

Kung mabagal ang app, nag-crash, hindi gumagana nang tama, o may problema sa display, buksan ang Settings > Version Information.

  • Piliin ang performance test upang sukatin ang pagproseso sa kasalukuyang device. Ipinapakita ng resulta ang petsa at oras ng pagsubok, pangalan ng device, bersyon ng OS, at mga oras ng pagsukat.
  • Piliin ang diagnostic log upang tingnan ang mga uri at resulta ng operasyon, oras ng pagproseso, at bilang ng mga pahina. Maaari mong kopyahin ang nilalaman sa clipboard at ilakip ito sa bug report kung nais mo.

Hindi itinatala sa log ang mga pangalan o path ng file, nilalaman o metadata ng PDF, mga password, o personal na impormasyon. Walang tampok na awtomatikong nagpapadala ng mga resulta o log sa labas ng device, at awtomatikong binubura ang mga log na lampas na sa 14 na araw.
