Patakaran sa Privacy

Huling na-update: Oktubre 5, 2026

Ipinapaliwanag ng Patakaran sa Privacy na ito kung paano pinangangasiwaan ni tyamada (ang “Developer”) ang impormasyon sa Mihiraki PDF Utility (ang “App”).

1. Mga PDF file

Ang mga PDF file na pinili sa App at ang mga pagbabagong ginawa mo ay pinoproseso sa iyong device upang maibigay ang mga tampok ng App. Walang tampok ang App na nagpapadala, nag-iimbak o nangongolekta ng iyong mga PDF file sa server ng Developer.

2. Pangongolekta ng data

Hindi nagpapadala ang App ng personal na data gaya ng pangalan, email address, lokasyon, contacts, browsing history o advertising identifier sa server ng Developer. Hindi kailangan ng user account.

3. Mga lokal na diagnostic log

Nagse-save ang App ng mga diagnostic log sa iyong device upang makatulong sa pagtukoy ng sanhi ng mga crash, slowdown, maling paggana, at problema sa display. Maaaring kabilang sa mga log ang mga uri at resulta ng operasyon, oras ng pagproseso, at bilang ng mga pahina. Hindi itinatala ang mga pangalan o path ng file, nilalaman o metadata ng PDF, mga password, personal na impormasyon, o iba pang nilalaman ng file. Walang tampok ang App na nagpapadala ng mga log na ito sa labas ng device. Maaari mong tingnan at kopyahin ang mga ito sa Settings > Version Information. Awtomatikong binubura ang mga record na lampas na sa 14 na araw.

4. Mga In-App Purchase

Ang opsiyonal na support purchase ay pinoproseso sa Apple StoreKit at App Store. Hindi direktang natatanggap o iniimbak ng Developer ang mga detalye ng bayad tulad ng credit card number. Nalalapat ang patakaran sa privacy ng Apple sa impormasyong pinoproseso ng Apple.

5. Mga serbisyo ng third party

Walang third-party advertising o analytics SDK ang App na nilayon para sa behavioral tracking. Nalalapat ang mga tuntunin at patakaran ng Apple sa App Store, StoreKit at mga serbisyo ng operating system.

6. Ang website na ito

Naka-host ang website na ito sa GitHub Pages. Maaaring malapat ang Privacy Statement ng GitHub sa teknikal na impormasyong nalilikha kapag ina-access mo ang site. Hindi gumagamit ang website na ito ng sarili nitong cookies, advertising o analytics.

7. Privacy ng mga bata

Hindi sinasadyang mangolekta ang App ng personal na data mula sa sinumang tao anuman ang edad.

8. Mga pagbabago sa patakarang ito

Maaaring i-update ang patakarang ito kapag nagbago ang mga tampok ng App o ang naaangkop na mga kinakailangan. Ang mahahalagang pagbabago ay iaanunsyo sa pahinang ito.

9. Pakikipag-ugnayan

Para sa mga tanong tungkol sa patakarang ito, makipag-ugnayan sa Developer sa pamamagitan ng GitHub Issues.
