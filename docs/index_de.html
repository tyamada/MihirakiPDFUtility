PDF-SEITENORGANISATOR

PDF-Seiten einfacher organisieren.

Dokumente zusammenführen, Seiten neu anordnen, drehen und entfernen, Eigenschaften bearbeiten und ein Anzeigepasswort festlegen – alles in einer übersichtlichen App.

Funktionen entdeckenHilfe und Support
FUNKTIONEN

Alle benötigten Seitenwerkzeuge an einem Ort

Öffnen Sie eine PDF-Datei, wählen Sie Seiten aus und bearbeiten Sie sie direkt auf Ihrem Gerät.

PDFs zusammenführen

Fügen Sie eine weitere PDF-Datei hinzu und verbinden Sie mehrere Dokumente.

Neu anordnen und extrahieren

Ordnen, duplizieren oder entfernen Sie Seiten und exportieren Sie nur die ausgewählten.

Drehen und einfügen

Drehen Sie ausgewählte Seiten oder fügen Sie leere Seiten ein.

Dokumentdetails bearbeiten

Ändern Sie Titel, Autor, Betreff und Schlüsselwörter.

Anzeigeeinstellungen

Speichern Sie Layout, Deckblatt und Leserichtung.

Passwortschutz

Legen Sie ein Passwort fest oder entfernen Sie es.

Diagnose direkt auf dem Gerät

Führen Sie unter „Einstellungen“ > „Versionsinformationen“ einen Leistungstest aus und zeigen Sie Diagnoseprotokolle an oder kopieren Sie sie – ohne externe Übertragung.
