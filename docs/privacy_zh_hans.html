隐私政策

最后更新：2026 年 9 月 22 日

本隐私政策说明 tyamada（“开发者”）如何处理 Mihiraki PDF Utility（“本应用”）中的信息。

1. PDF 文件

为了提供本应用的功能，您在本应用中选择的 PDF 文件及所做的编辑均在您的设备上处理。本应用不具备将您的 PDF 文件发送、存储或收集到开发者运营的服务器上的功能。

2. 数据收集

本应用不会向开发者运营的服务器发送您的姓名、电子邮件地址、位置、联系人、浏览历史记录或广告标识符等个人数据。无需创建用户帐户。

3. App 内购买

可选的支持性购买通过 Apple 的 StoreKit 和 App Store 处理。开发者不会直接接收或存储信用卡号等付款详情。Apple 的隐私政策适用于由 Apple 处理的信息。

4. 第三方服务

本应用不包含用于行为跟踪的第三方广告 SDK 或分析 SDK。Apple 的条款和政策适用于 App Store、StoreKit 和操作系统服务。

5. 本网站

本网站托管在 GitHub Pages 上。当您访问本网站时，GitHub 隐私声明可能适用于所产生的技术信息。本网站自身不使用 Cookie、广告或分析功能。

6. 儿童隐私

本应用不会故意收集任何年龄人士的个人数据。

7. 本政策的变更

本应用的功能或适用要求发生变化时，本政策可能会更新。重大变更将在本页面公布。

8. 联系方式

如对本政策有任何疑问，请通过 GitHub Issues 联系开发者。
