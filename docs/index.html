PDF PAGE ORGANIZER

A simpler way to organize PDF pages.

Merge documents, reorder, rotate and remove pages, edit properties, and set a viewing password—all in one straightforward app.

Explore featuresHelp and support
FEATURES

The page tools you need, all in one place

Open a PDF, select pages, and make your changes. Organize documents on your device without setting up a complicated editing environment.

⊕

Merge PDFs

Add another PDF and combine multiple documents into one.

↕

Reorder and extract

Rearrange, duplicate or remove pages, and export only the pages you select.

↻

Rotate and insert

Rotate selected pages or insert blank pages before or after them.

ⓘ

Edit document details

Review and change the title, author, subject and keywords.

▣

Set viewing preferences

Save page layout, cover display and reading direction in the PDF.

⌑

Password protection

Set or remove the password required to open an exported PDF.

◷

On-device diagnostics

Run a performance test, review diagnostic logs, and copy results for troubleshooting. Nothing is sent externally.
