隱私權政策

最後更新：2026 年 11 月 20 日

本政策說明開發者 Takuma Yamada 如何處理 MihirakiPDFUtility（以下稱「App」）中的資訊。

1. PDF 檔案

您在 App 中選取的 PDF 及所做的編輯都在裝置上處理。App 不會將您的 PDF 傳送至開發者營運的伺服器，也不會在該伺服器上儲存或收集這些檔案。

2. 個人資料

使用 App 無須建立帳號。App 不會將您的姓名、電子郵件地址、位置、聯絡人、瀏覽記錄或廣告識別碼等個人資料傳送至開發者營運的伺服器。

3. 裝置上的診斷記錄與報告

為協助找出 App 意外結束、執行緩慢或功能異常的原因，App 會在裝置上儲存有限的診斷記錄。記錄可能包含事件類型、操作結果、處理時間及頁數，但不含檔案名稱、檔案路徑、PDF 內容、文件後設資料、密碼或裝置名稱。App 會自動清除超過 14 天的診斷記錄。

診斷功能可在裝置上產生問題回報用的診斷報告，其中可能包含測試結果、App 和作業系統版本，以及因儲存空間不足而略過測試等資訊。這份報告不含使用者文件、密碼、檔案路徑或個人裝置名稱。個別的效能測試結果則可能顯示裝置名稱。

App 不會自動對外傳送診斷記錄、診斷報告或效能測試結果。您可以在 App 內檢視內容，依需要手動複製到剪貼簿，也可以透過系統分享功能手動分享診斷報告。

4. App 內購買

支持者圖示是可選購的項目，由 Apple 透過 StoreKit 與 App Store 處理。開發者不會直接取得或儲存信用卡號碼等付款資料。Apple 處理的資訊適用 Apple 的隱私權政策。

5. 第三方服務與範例 PDF

App 未使用用於追蹤使用者行為的第三方廣告或分析 SDK。App Store、StoreKit 及作業系統服務適用 Apple 的條款與政策。

當您開啟範例 PDF 清單時，App 會嘗試從 GitHub 的 raw.githubusercontent.com 取得公開的範例目錄。您選擇下載範例時，PDF 檔案會從 GitHub Releases 下載。連線時產生的技術資訊（例如 IP 位址）適用 GitHub 的隱私權聲明。

6. 本網站及外部連結

本網站由 GitHub Pages 代管。您瀏覽本網站時產生的技術資訊，可能適用 GitHub 的隱私權聲明。本網站本身不使用 Cookie、廣告或分析工具。

選取 YouTube 教學連結會開啟外部頁面。透過瀏覽器造訪該頁面時，YouTube 處理的資訊適用 Google 的隱私權政策。

7. 兒童隱私

App 不會刻意收集任何年齡使用者的個人資料，包括兒童的個人資料。

8. 政策變更

App 功能或適用要求有變動時，本政策可能隨之更新。重大變更會在此頁面公告。

9. 聯絡方式

如對本政策有疑問，請透過 GitHub Issues 聯絡開發者。
